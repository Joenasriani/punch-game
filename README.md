# STRESS BUSTER 3000

**Game lineage:** STRESS BUSTER 3000  
**Status:** browser game / base build  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

STRESS BUSTER 3000 is a browser arcade interaction game built around punching on screen targets with mouse, touch or pointer input.

## Lineage

This repository is the base browser build.

`Joenasriani/punch-game-xr` is the WebXR edition of the same game lineage. It is an alternate implementation, not a separate unrelated game.

Existing branches and historical files are retained as development history.
